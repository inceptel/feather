Rows are the union of the autonomous source (api/sessions?mode=ralph&limit=300) and any row of the sessions source (api/sessions?limit=300) with mode = ralph or workflow.enabled, de-duplicated by id. The sessions source lists only the most recent 300 discovered sessions, so an older workflow-only chat would be missing. State is derived from the source fields only: no ralph object → unknown; ralph.status = blocked → blocked even when ralph.enabled is false (the callback is off because a human must answer); ralph.error or status = error → error; enabled with status working/scheduled → working; enabled with no status → unknown; workflow.phase = reviewing → reviewing; status waiting or phase waiting → waiting; status stopped/complete → history. Joins use session IDs only: usage rows by sessionId, reviewer lines by chatPair.reviewerSessionId, running rules by runtime.running.sessionId. Sessions without a chatRole are Room residents or plain sessions; their Room is not in the source rows, so it is not shown.

Refreshes every 30 s while this tab is visible; nothing is fetched while it is hidden. Usage rows are the top 12 sessions by tokens in each window (api/usage caps bySession at 12), so a quiet chat may have no row even when it used tokens.
